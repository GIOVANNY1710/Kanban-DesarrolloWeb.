# 📌 Proyecto Kanban - TEINCO

Este proyecto académico presenta la **metodología Kanban** como herramienta de gestión visual para optimizar el flujo de trabajo y la productividad en equipos de desarrollo y entornos organizacionales.

🌐 **Demo en línea:** [Ver Proyecto en GitHub Pages](https://reyes3122.github.io/Kanban-Proyect/index.html)

---

## 📖 Contenido del proyecto

1. **Introducción**  
   Explicación general de la metodología Kanban.

2. **Justificación**  
   Razones por las cuales esta metodología aporta valor a los procesos de trabajo.

3. **Marco Teórico**  
   Conceptos, fundamentos y elementos básicos de Kanban.

4. **Conclusiones**  
   Beneficios obtenidos mediante la implementación de Kanban.

   ```bash
   cd Kanban-Proyect
   ```
3. Abrir el archivo `index.html` en el navegador.
